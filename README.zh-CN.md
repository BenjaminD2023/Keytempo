# Keytempo

原生 macOS 菜单栏打字节奏统计工具，使用 Swift、AppKit 和 SwiftUI。所有统计保存在本机。

[English](README.md) · [下载](https://github.com/BenjaminD2023/Keytempo/releases) · [MIT 许可](LICENSE) · [参与贡献](CONTRIBUTING.md) · [安全报告](SECURITY.md)

## 统计能力

**全局监听提供上下文过滤后的估算；已确认数据目前只覆盖内置验证输入区。** 文本框角色不能证明某个键真正插入了文字，全局监听也无法获取系统拼音的真实上屏字符数。

| 单位 | 口径 |
|---|---|
| 估算 WPM | 当前输入源语言的输入过程 KPM ÷ 5，包含组合与编辑，不代表真实词数 |
| CPM | 真实提交的扩展字素簇 ÷ 有提交覆盖的输入过程时间，仅接入路径可用 |
| KPM | 有效操作间隔数 ÷ 实际间隔时间；菜单栏可单独选择，历史保留独立列 |

菜单栏主要速度显示**当前输入段速度**，活跃时约每秒更新。主要单位随当前输入源语言切换：`zh/ja/ko/th/lo/km/my` 使用 CPM，其他已知语言使用估算 WPM。切换输入源后清空当前速率，等待新的有效样本，不将先前的英文 WPM 留作中文速度。全局中文缺少上屏数据时显示 `— CPM`，仍可切换到辅助 KPM。KPM 合并全部记录语言的近期有效间隔，不连接不同输入源之间的停顿。

至少有 4 个有效间隔、0.5 秒才展示速度。每段首键仍计入总量；自然空闲后速度冻结并标为最近／已停止；已知命令或上下文中断会清空当前速率。等待不会增加打字时长，也不会使速度下降。

今日概况与菜单弹窗只展示一个**日常敲键数量（估算）**，合并其他 App 中全部记录语言的输入。今日段内时长和加权 KPM 也合并计算；主要 WPM／CPM 仍按当前输入源语言显示。快捷键和上下文过滤继续生效，空格不进入全局敲键数量和 KPM。大数使用 K／M／B 缩写、最多三位数字，例如 `1.49K`，悬停可查看完整整数。历史提供每日合并数量／KPM 汇总，并保留分语言 WPM／CPM 明细。已确认编辑器明细保留在“验证输入”页和原始 CSV 中。

## 安装与授权

从 [Releases](https://github.com/BenjaminD2023/Keytempo/releases) 下载 macOS ZIP，将解压出的 `Keytempo.app` 放到 `/Applications` 或 `~/Applications`，固定位置后授权。目前应用使用临时签名，**尚未通过 Developer ID 签名或公证**；重新构建、替换或移动后，macOS 可能要求重新授权。

部署目标为 macOS 13+。目前实机验证限于 Apple M4 MacBook Air、macOS 27、Apple Silicon（arm64）；旧系统和 Intel 执行未实测。请以发布附件注明的架构为准。

全局估算需要在“系统设置 → 隐私与安全性”允许 Keytempo 的：

1. **输入监控**：被动接收按键时间、键码、修饰键和重复标记。
2. **辅助功能**：仅查询焦点控件角色及可编辑性元数据。
3. 返回应用设置，点击“重新检查权限”；必要时重新选择已安装的 App 并重启。

内置“验证输入”无需全局权限。安全输入、权限不足、未知或过期上下文会停止全局归类；没有收到按键不能证明用户没有打字。

## 功能与设置

- 菜单栏速度、今日总量、暂停／恢复和可选登录启动。
- 中文／English 界面，与记录语言独立。
- 选择要记录的输入源语言；明确不选任何语言即停止统计。
- 分语言 7／30／90 天、1 年、5 年趋势，独立 KPM 列、CSV 导出和应用排除。
- 不含输入内容的可关闭诊断，以及真实 `NSTextView` 输入回调验证路径。

90 天以内按日汇总，1 年按周、5 年按月。速度从汇总分子和真实覆盖时长重新计算，不直接平均各日速度；语言、证据和规则边界保留。长范围仅在打开或选择时按需查询 SQLite，不增加启动缓存，也不逐秒轮询数据库。选择五年只能查看已保存的历史，不会补造尚未记录的过去活动。启动时按五个日历年及最多 50,000 条汇总记录保留历史，关闭历史页会释放已加载的记录。

语言按键盘／输入法声明归类，不分析文字内容。中文输入法内直接输入英文仍归中文输入源。代码、数学、标点和重复文字不会因“不像单词”被过滤。

## 构建

安装 Xcode 或 Command Line Tools 提供的 Swift 工具链，在仓库根目录执行：

```sh
./scripts/test.sh
open dist/Keytempo.app
```

测试使用 Swift Testing，需要 Swift 6+；本机使用 Swift 6.4，该测试框架需要 macOS 14+。只构建可运行 `./scripts/build.sh`，产物位于 `dist/`。版本及 GitHub 发布步骤见 [发布说明](docs/RELEASING.md)。

## 口径与局限

`KPM = 60 × 有效间隔数之和 ÷ 有效间隔真实秒数之和`。同段 n 个事件有 n−1 个间隔；单键增加总量，不虚构持续时间。自适应模型使用有界的中位数／MAD 样本及慢速候选，不在末次按键后追加固定活动时间。

已识别的快捷键、导航、生成操作与未知上下文会切断连续段。删除单独统计为编辑，不称为错误率；Shift／Option 正常文本输入保留，系统自动重复不算独立手动敲键。输入法估算模型在可编辑区域中依据近期输入，将候选数字、方向和回车归为 probable 组合操作；这只是用途估计，不等于观察到了组合文本或真实上屏字符。缺少相应上下文时，普通导航与不明用途操作仍排除或保留未知。全局统计跳过空格；在上下文有效时，空格不切断输入段，下一条被接受的间隔仍计入完整真实时间。验证输入区继续依据真实提交回调计字符；选词确认按键不会额外冒充字符。

全局元数据无法识别所有自定义快捷键或宏。终端、Vim、游戏及自定义编辑器可能无法覆盖。空格排除／候选估算的新规则只应用于之后的输入；历史汇总保留，不反推改写。同一天存在新旧规则时，不合并不可比的每日速度，因此可能显示不可用；数量仍保留，当前速度会从更新后重新采样。

CPM 不从拼音按键推算。粘贴、补全和已知生成内容不直接进入手动字符量。具体覆盖及未完成实测范围见 [验证文档](docs/VALIDATION.md) 和 [适配器说明](docs/ADAPTERS.md)。

## 隐私与数据

应用不联网，不保存输入文字、可还原按键序列、剪贴板、文档、窗口标题或网页地址。已确认编辑器只在提交回调中临时计数，再传递数量及覆盖元数据。

- 数据库：`~/Library/Application Support/TypingSpeed/statistics.sqlite`
- 偏好：`~/Library/Preferences/local.benjamin.TypingSpeed.plist`
- 为兼容已有历史和设置，保留旧 Bundle Identifier `local.benjamin.TypingSpeed`。

有新数据时约 30 秒批量保存；正常退出、暂停和睡眠尽力提交，强退或崩溃可能丢失未保存部分。诊断默认关闭，仅保留有界内存摘要。功耗与资源范围见 [PERFORMANCE.md](PERFORMANCE.md)、[POWER.md](POWER.md)：尚未验证完整电池增量低于 1 W，打开完整界面后的 RSS 目标仍未达成。

[反馈问题](https://github.com/BenjaminD2023/Keytempo/issues) 时请提供版本、系统、输入法、受影响应用与权限／上下文状态，使用虚构内容复现。不要上传实际输入文字、聊天记录、统计数据库或系统权限数据库。
