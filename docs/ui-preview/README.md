# 合成界面测试图

这些图片是更名及 1.1 语言／WPM／CPM 更新之前的布局夹具，保留作历史验证材料；当前界面以应用及源文件为准。

本目录 PNG 来自真实 SwiftUI 视图在隐藏 AppKit 宿主中的渲染，使用临时 AppModel 接口桩与合成数据。所有输入数量、权限状态、节奏模型和 callback p99 仅用于检查布局，**不代表实测结果**。没有采集用户屏幕、原文或统计数据库。

- `menu.png`：菜单概况。
- `today.png`：过程节奏与文字敲键节奏分开显示。
- `history.png`：7 天的敲键数量图和每日统计表。
- `settings.png`：原生设置表单，可向下滚动查看数据操作。
- `diagnostics.png`：元数据诊断布局，所示 1.2 微秒为夹具值。
