# Keytempo app icon

Source: `AppIcon.png`; native multiresolution package: `AppIcon.icns`.
Generated with the built-in imagegen tool, then resized and packaged by macOS `sips` / `iconutil` using `scripts/build-icon.sh`.

The icon has no lettering and is retained after the app was renamed Keytempo. Original generation prompt (historical name preserved verbatim):

> Use case: logo-brand. Asset: production macOS app icon, square 1024x1024, for a private lightweight typing rhythm tracker named TypingSpeed / 字间. Create a refined native macOS icon: one smooth rounded square ceramic keycap in soft ivory, slightly elevated bevel, with a simple dark graphite abstract glyph combining three short keyboard-key strokes and a small ascending rhythm pulse. A tiny restrained mint accent on the pulse. Clear immediately readable silhouette at 32 pixels. Main squircle occupies about 88% of the image, centered; gentle realistic shallow depth and soft ambient shadow, premium quiet utility, contemporary macOS app icon craft. No lettering, words, numbers, speedometer dial, extra objects, background scene, display mockup, watermark, or frame. Transparent outside the rounded square; genuine alpha, not checkerboard. Return one single finished icon, straight-on view.
